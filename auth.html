DialysisSafe on GitHub Pages

This site is a static GitHub Pages site. It cannot securely verify a username, password, or passkey because it has no private server to keep a secret.

No login is configured here. Do not enter a real username, password, API key, or health information into a browser-only login page.

There is no username or password to change for this Pages version. Putting a password, password hash, or GitHub Actions secret into these website files would expose it to visitors.

If you need real access control, use an organization with GitHub Enterprise Cloud private Pages and manage access using GitHub accounts and repository permissions. Otherwise, keep this site public and do not include private data.
